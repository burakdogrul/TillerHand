```

**İyi giden:** [...]
**Zaman kaybettiren:** [...]
**Tekrar eden AI hataları:** [hata türü — kaç kez — nasıl çözüldü]
**Eksik/gereksiz kontrol:** [...]
**Projeye eklenen kurallar:** [dosya: kural]
**Kite önerilen değişiklikler:** [dosya: değişiklik — onaylandı/reddedildi]
```

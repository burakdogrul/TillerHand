# Metrics

> Data, not feeling. Studies show that developers working with AI can feel faster while actually working
> slower (METR, 2025). Here the real course of the project is recorded monthly.
> `/maintain monthly` and `/retro` each add one row; the `/dashboard` dashboard shows the trend.

## Definitions

- **Completed tasks:** The number of roadmap tasks checked off in the period.
- **Avg. task duration (min):** The average of "Time (min)" in `docs/workflow/cost-log.md`.
- **Avg. limit cost (%):** The average 5-hour usage difference in the same log.
- **Fix rate (%):** `fix` commits in the period ÷ (`feat` + `fix`). If high, new features break often.
- **Rollbacks:** The number of `revert` commits in the period.
- **Duplicate code (%):** The duplication ratio in the `npx jscpd` report.
- **Open critical:** The number of board RET findings that are not closed.
- **Acceptance tests (%):** The share of MVP acceptance criteria whose tests pass.
